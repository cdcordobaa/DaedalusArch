## 3. What changed in code

- `src/shared/apg2-scope.ts` (new) holds the a priori scope:
  - the test-file and test-composition-root patterns;
  - the composition-root name patterns;
  - the `composition-root` role;
  - `APG2_MIN_TYPES_FOR_DISTANCE = 4`.

  These are anchored regexes that mean the same in JavaScript and in Cypher `=~`.
- `src/apg-extractor/apg2/components.ts`, with `apg2` on only:
  - test code belongs to no component;
  - inferred entry files are the root index only;
  - the entry set (declared or inferred) is closed over barrels the entry re-exports (`RE_EXPORTS`, inside the component).
- `src/fitness-compiler/apg2-templates.ts` adds these predicates:
  - `boundary-type-leak`: composition-root and test scope on the member;
  - both `deep-import-*`: composition-root, test and ACL scope on the importing file, with the ACL exemption only for `kind = 'module'`;
  - `component-adp-cycle`: `d.kind <> 'layer'`;
  - `component-main-sequence-distance`: `c.kind <> 'layer' AND c.typeCount >= $minTypes`;
  - `undeclared-async-coupling` and both I/O templates: test scope.

  No tier changed.
- `src/fitness-compiler/apg2-in-memory.ts`:
  - the mirrors apply the same scope;
  - `apg2Params` binds `compositionRootLayers`, `compositionRootPatterns`, `testPatterns`, `aclPatterns` and `minTypes`;
  - the new `compositionRootLayers(layerModel)` returns the declared role layers plus the structural rule of `bindHexagonalLayers`.
- `scripts/v1.3/apg2-live.ts` passes the scope parameters to Neo4j.

**Known edge of the a priori structural rule.** In a two-layer model where the outer layer may import the inner one and nothing points to the outer layer, the outer layer is detected as a composition root. The `apg2Params` unit test shows this with `adapters → core`. In that model `boundary-type-leak` cannot fire anyway, since the infrastructure layer is also the controller layer. But deep imports from that layer would be exempt. None of the reference specs or fixtures has this shape. It is recorded here for the author rather than changed after measuring.
