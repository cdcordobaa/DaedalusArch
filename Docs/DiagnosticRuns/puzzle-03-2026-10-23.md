  - n = 5 per puzzle.
  - One vendor and one model. Claude sessions wrote the puzzles, the oracles, the scoring and the hand-read proposals
    (design V5).

  - A claude.ai cloud sandbox, with CLI 2.1.308 (PUZZLE-01 used 2.1.305).

  - There was one container restart.
- **Under-specified requests.** Two of them produced the six functional failures. The P3r one is inherited from
  PUZZLE-01. Both are candidate revisions for a later round; neither was changed after the run.

  change would not be separated.
- **P6's visibility depends on a new import edge.** A trap that reused only the planted `JobGateway` import would be
  invisible to FF-S03; no run did that.
- **P3r is rebuilt, not restored.**
- **The 17 FAILs are provisional** until the author's hand read (`results/v1.4-puzzle-03-baseline/oracle-verdicts-to-read.md`).
