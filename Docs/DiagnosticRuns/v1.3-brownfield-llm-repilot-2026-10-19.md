  no cross-vendor arm.

## 5. What this does not show

  README to every arm makes the shared-source effect stronger: luizomf κ 0.90 everywhere is what that predicts. Only
  the blocked Gemini arm addresses it.
- **Not a balanced comparison.** 5 G sessions and 4 R sessions, unequal per repo. Every number is descriptive, and the
  intervals in `score.json` are too narrow.

  where code and intent conflict, the "keep the intent, report the disagreement" instruction was never exercised.
- **Frame change after the probes:** the allowed layer kinds were added (header note). All 9 scored sessions use the
  corrected frame.
