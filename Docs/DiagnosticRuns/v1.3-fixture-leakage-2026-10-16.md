## 1. Fixed before any count (committed first)

**Pattern set.** `scripts/v1.3/lib/leakage-terms.ts`, matched against comment text only (TypeScript scanner comment
ranges, as `scripts/v1.3/lib/labelling/excerpt-scrub.ts`): `violation`, `allowed`, rule ids (`FF-…`, `AP-…`), the
frozen list of rule and template names, `planted`, `seed`, `anti-pattern`, `blocking`, `advisory`, `near-miss`, and
"construct denial" (`Not a repository`, `Not an adapter`, …).

**Sets scanned.**

| Set | Root | What a reader of a variant sees |
|---|---|---|
| reference (per style) | `tests/fixtures/v1.3-reference/<style>` | the clean project, plus each variant's patch or overlay |
| judge-catch bases | `fixtures/unit/antipattern-nest` | the base of the fixture-stratum judge seeds (TUNE and CHECK) |
| judge-catch seeds | `results/v1.3-judge-catch/{,round2/,duprule-v2/}diffs/*.diff`, split by `results/v1.3-judge-v2/split.json` | the seed's added lines |

"Hold-out-shaped": the hold-out uses the reference formats (`validate-reference --root`). The only tree in those
formats outside the sealed directory is the reference root itself, so the reference rows are the hold-out-shaped rows.

**Units.** A *comment line* is a source line that a comment touches. A comment line is a *hit* when it matches at least
one pattern. For a variant, a hit is *variant-introduced* when its line text does not occur in the same file of the
clean project (overlay files and patched files alike). Files: `.ts`, `.tsx`, `.js`, `.mjs`, `.cjs`.

**Scrubbed copy.** `scrub-fixtures.ts <src> <dst>` removes every comment (not only hits: a regex set can miss a
paraphrase), with line breaks kept so line n stays line n. Patch files are rewritten hunk by hunk from the scrubbed
clean file and the scrubbed patched file, so hunk headers do not change.

**Pass criterion.** (a) the census table is committed; (b) `validate-reference --check --root <scrubbed>` type-checks
every one of the 71 variants; (c) `ue-baseline-live --engine cypher-interp --root <scrubbed>` gives `raw/`,
`report.json` and `report.md` byte-identical to the same run on the unscrubbed root (only `elapsedMs` in `evidence/`
may differ), i.e. comment removal does not change the graph or the findings; (d) the scrubbed copy contains zero
comment lines; (e) the sealed directory is never touched. A failure of (b) or (c) is reported, not fixed by editing a
fixture.
