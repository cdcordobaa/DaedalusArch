version?") for the 71 reference variants only. It is not a validity estimate; nothing was tuned, no code, template,
tier, preset or spec changed.

## 5. What this does and does not show

- It shows that the reference results do not move between the 5.26 LTS line and the last 2025 calendar release, with
  the bundled APOC of each, at the Cypher 5 default. Combined with the interpreter result, the 71 reference results are
  reproduced by three independent executors of the same template text.
- It does not cover: the Cypher 25 language mode (`CYPHER 25` prefix or a Cypher 25 default database), 2026.x
  releases, Enterprise edition, other runtimes (`runtime=pipelined` is Enterprise only), devset-b, the external set, or
  any hold-out material (never touched, rules block item 2).
- Row order without `ORDER BY` (trap T1) and float last bits of unordered aggregates (T2) are store- and
  history-dependent on any version; every template has a complete `ORDER BY`, so neither reaches the reported files.

Not done: no jest run (no source file changed on this branch); no Neo4j 2026.x; no Cypher 25 mode run.
