## 2. Decisions

- **D-e (decision-chronology row 13).** The filter-and-explain grounding default goes back to `bareLines: 'longest'`,
  the documented rule. R20 `'attributed'` stays available as an opt-in. R20 changes judge-stage results (3 of the 66
  true rows rejected as ungrounded, all three false rejections), so under D-b's rule (row 11) it stays off. After the
  change, the committed 65/66 and 114/114 reproduce.
- **Results-path guard (row 14).** v1.3's result folders are registered as allowed by folder pattern, not path by path.
  The v1.2E protections are unchanged. Re-scoping the guard to v1.2E plans only was not chosen, because it would drop
  the protection of the v1.2E result folders against later commits.
- **Recorded after the fact (row 15).** #235's hint-audit default word lists. This is not a new decision; the row
  records one that MT7 had described as "off by default".
