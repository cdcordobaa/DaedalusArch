## 3. Method

**Identity.** One identity is one distinct blocking edge, source file → target file (`STUDY2_S2D01`, G08 §2.1). FF-S01 and FF-S03 on the same edge count once. Under the s2d-01 preset a cycle is its sorted file set. The G08 variant (a cycle as its set of directed edges) is reported beside it. Only findings labelled `correct` count.

**Renames.** ρ is empty. The probe snapshots are plain directories (ID-9). The harness snapshots hold no blocking finding, so D does not depend on ρ there.

**Outcomes.** E_t is the set of identities in the step-t final snapshot.

- **Y1** = |E_1|.
- **D** = Σ_{t=2..min(k,5)} |E_t \ ∪_{s<t} E_s|.
- **Y_last** = |E_k|, at the last step the run has.

**Secondaries.**

- D under the memo identity (`MEMO_COMPAT`, kTo = 5): rule, template, file and target, so FF-S01 and FF-S03 count separately.
- D under the G08 edge-set cycle key.
- The number of inherited step-1 identities removed by the last step.

**Probe-1 tool arm.** This arm fixed step 1, so its post-fix Y1 is 0. Its pre-fix step-1 findings are identical to the `none` arm's. Because the two arms have different step-1 trees, probe 1 never formed an s2d-01 shared-start block.

### 4.3 Gate D9: the planted effect

**Set-up** (`d9.json`):

- 32 blocks. Each has three cells (none@L2, none@L3, mcp@L2), all starting from one real probe-1 Layered step-1 tree, cycling over market-vendors, youth-league and hive-health.
- Each cell's number of new identities is drawn NB(2.67, 4.27) with `nbDraw`. The `shared` model uses one gamma frailty per block, as in the library.
- The draws are materialised as findings: first the source run's real new identities, in the order they appeared, then synthetic FF-S01 edges.
- The planted effect deletes each new identity of the treated cell with probability f.
- D is then recomputed by `driftRun` from the materialised snapshots and tested with `signFlipSimP` and `holmReject` (H1 = none@L2 vs none@L3, H2 = none@L2 vs mcp@L2). These are imported from `scripts/v1.3/lib/level-power-sim.ts`, unchanged, because the library has no drift mode yet.
- 2,000 simulations per scenario, seed 20261019.

| Scenario | Cells | Reject H1 | Reject H2 | Family-wise | Recovered RR (H1, H2) |
|---|---|---|---|---|---|
| RR 1 (size) | independent | 0.018 | 0.020 | 0.035 | 1.02, 1.02 |
| RR 1 (size) | shared start | 0.022 | 0.017 | 0.034 | 1.02, 1.01 |
| mcp f = 0.75 (RR 0.25) | independent | 0.039 | **0.999** | 1.000 | 1.01, 0.26 |
| mcp f = 0.75 | shared start | 0.035 | **1.000** | 1.000 | 1.01, 0.25 |
| mcp f = 0.50 (RR 0.5) | independent | 0.032 | **0.755** | 0.762 | 1.02, 0.51 |
| mcp f = 0.50 | shared start | 0.037 | **0.892** | 0.894 | 1.01, 0.51 |
| both f = 0.75 | independent | 0.9995 | 1.000 | 1.000 | 0.25, 0.25 |
| both f = 0.75 | shared start | 1.000 | 1.000 | 1.000 | 0.25, 0.26 |

Monte Carlo SE is ≤ 0.010 per cell. In every cell run, D from `driftRun` equalled the number of identities the plant left (0 mismatches). So the identity, union and step logic recover the planted removal exactly, and the test recovers its sign: every rejection of H2 is in the planted direction.

**Size.** At RR 1 the test is conservative: about 0.02 per hypothesis, 0.035 family-wise. Two things push it below α: the discrete sign-flip, and Holm over two.

**Power against s2d-01 §3.**

- RR 0.25: agrees (≥ 0.999 vs 1.00).
- RR 0.5: lower. Independent cells give 0.755 ± 0.010, against 0.79. The shared start gives 0.892 ± 0.007, against 0.93.
- s2d-01's scratch driver was not committed, so the cause cannot be checked here. Thinning NB(μ, θ) at rate r is exactly NB(μr, θ), so this check and an NB draw at μr should agree in distribution.
- The difference therefore lies in the driver, not in D. Monday's committed `--outcome drift` mode should settle it. Until then, read RR 0.5 power at 32 independent blocks as **about 0.76**, not 0.79.

**Real-data exercise** (`runs.json` `realDataExercise`). The probe-1 `none` and tool D, paired by task, give differences of 1, 2, 5, 0, 0 and 0. The exact sign-flip p is 0.25, the smallest attainable with three non-zero blocks. This only shows the pipeline running on real records. It is not an effect estimate: the arms have different step-1 trees, the work was Opus by hand on development tasks, and s2d-01 §2 already discloses the glimpse.

That fits REV-03's reading that D measures propagation of inherited patterns. So the Y1 line is the early read on Tuesday: a Layered pilot run with Y1 = 0 is very unlikely to reach D ≥ 1.
3. **Clean and Hexagonal.** Mean D is 0.08 (1 of 13) over 13 Opus and Sonnet `none` runs, and Y1 is 0 everywhere. This supports s2d-01's decision not to run these styles, and REV-02 item 5's "report the zeros as a finding".
4. **DDD** has no D at all until T1 is resolved, so D15's DDD question gets no help from existing data.
5. **D9 is met for the analysis code.** The pipeline recovers a planted effect and holds size. The pilot-data run of D9 that s2d-01 §6 asks for is still due on Tuesday, on the pilot's own snapshots.

## 6. Limitations

- **Development data only.** These are rehearsal and pilot tasks, not Study 2 tasks. None are hint-audited for drift pressure, apart from the probe-3 subset.
- **Most of the signal is Opus by hand.** Every non-zero D comes from one Claude session working by hand, which had read about the instrument (probe-1 and probe-2 reports). That session is not the loop harness, not confined, and not the Study 2 generators.
- **n is tiny.** There are 3 runs with D > 0 and one replicate per cell. The θ of 4.27 rests on three values.
- **k varies.** k is 4 for probe 2, probe 3, the loop pilot and two probe-1 tasks, not the registered 5. D in those runs counts steps 2–4 only.
- **No shared-start block exists in the data.** The probe-1 tool arm fixed its own step 1, and the loop pilot's `gate` arm grew its own step-1 tree.
- **No post-seal overlay.** The deviation's blocking tier is the sealed tiers plus the post-seal overlay (ADR-V14-01, -02). The committed evaluations predate the overlay, so FF-P07 (an HTTP framework import inside the application, blocking in Clean, Hexagonal and DDD but not in Layered) was not scored. The Layered figures, the s2d-01 inputs and D9 are unaffected. The Clean and Hexagonal zeros are zeros under the sealed tiers only, and a re-score with the overlay could change them. The identity used is s2d-01's (sorted-file cycles); the G08 edge-set variant was checked and agrees here.
- **ρ is empty everywhere.** This has no effect on these numbers, because no harness snapshot holds a blocking finding. It will matter for the pilot.
- **The D9 synthetic edges are FF-S01 only.** The NB model and the s2d-01 inputs (μ 2.67, θ 4.27) are assumptions carried over, not measured on Sonnet or Gemini.
- **DDD** is unscored because of T1, which was not fixed here.
