## 4. Why the hold-out cannot run blind (exactly what was seen)

1. The sealed directory's hash (sealed-hashes method) is `1379b561…`, equal to `sealed-hashes.md`. The blind set `v1.3-blind` is `82209b39…`, also equal.
2. A script copied it to a 0700 temporary directory outside the repository, named `v1.3-holdout`. `holdout-run.ts --dry-run --expect-sealed-sha256 1379b561…` matched the hash. It then reported no style directory at the top level (only `input/` and `out/`), and "styles absent from the hold-out: all five".
3. Structure-only dry runs on the subdirectories:
   - `out/`: five style directories, 595 files. Clean-architecture, layered, nestjs and hexagonal: `ENOENT … expected-findings.json` (the file the runner's loader opens). ddd: "missing clean … (overlay format)".
   - `input/`: 12 files, a `schemas` directory, no style.
4. Only those runner messages were displayed: the expected file's basename, with paths redacted. No case, manifest or file content was seen. The copy and the logs that name sealed paths were deleted afterwards.

**What it needs.** The hold-out was written in a layout the registered loader (`scripts/v1.3/lib/holdout-run-main.ts`, `reference-model.ts`) does not read. The runbook rule applies: "Any other structure problem stops the freeze: the hold-out is never edited." Running it needs a loader, or an adapter, for that layout. Writing one requires someone to look at the sealed layout: the author, or a session the author clears for it. That is not blind. It also changes `scripts/v1.3/` (a frozen path), so it needs a new X, a re-run of F7–F12, and a moved or second freeze tag. The F8 record run would then be a second run unless the change is confined to the hold-out loader, which the dev set does not use.

**Consequence for Study 2.** Until the hold-out runs, no style reaches the ADR-V14-04 bar, and gate V4 stays red. Layered (the confirmatory style) stays confirmatory only if the per-arm non-differential miss check of ADR-V14-04 §4 passes; otherwise it is exploratory. This is the risk `ops/05` names ("the hold-out is weak: report it as a limitation; 2b still runs").
