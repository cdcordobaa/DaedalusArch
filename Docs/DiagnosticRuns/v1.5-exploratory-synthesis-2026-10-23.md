## 2. Insights (development readings)

- **The tool helps where the graph can see.** P1 went 0/5 to 4/5 and P6 0/5 to 5/5; the blind control P3r stayed
  unchanged (gate 0/5, 0 gate replies), which is the expected pattern when the facts do not cover the trap.
- **v1.4 is blind where agents err; v1.5 sees it.** The frozen D was 0 in every DRIFT-01 cell while D_v15 on DDD went
  6 to 0 for both pull and gate.
- **Delivery matters for inherited debt.** The gate removed the inherited cross-context write in 3/3 blocks; pull
  reported it in 13 of 14 calls and it stayed in 3/3. Pull's agents still avoided the new write.
- **Agents name the rule even on trap steps** (COMPREHEND-01, entry 16), so the trap rate is not a comprehension
  failure. Delivery at the moment of action is the track this points to.
- **Graph tools cut cost on small codebases at equal accuracy** (scope note above); no accuracy claim, and no claim
  about large codebases.
- **Semantic layer:** U3 passes (24/24, designed set), S3 passes, S2 fails (D5 recall unchanged; the lock-form
  boundary moved rather than sharpened).
