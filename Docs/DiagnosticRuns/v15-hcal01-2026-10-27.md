Date: 2026-10-27. Zero model calls for scoring. **Development material**: rules were revised after reading these
cases. Hexagonal is the confirmatory style of the final study, and this is its first calibration.

  The row → rule map was fixed from the spec's fitness functions before the first scoring.

## Revisions

- **R-D9 does not run on Hexagonal specs.** A use case returning a domain object through its inbound port is normal
  in Hexagonal. R-D9 is a DDD published-contract rule. This mirrors R-INJ, which does not run on Layered.
- **R-AXA (new):** an adapter file imports a file of another adapter package. The package is the folder under
  `adapters/in|out`, `adapters` or `infrastructure`. The frozen dependency-direction rule does not report
  inbound-to-outbound imports between two adapter layers.
- **R-H5:**
  - A name imported from a third-party package and used in a port signature counts as a vendor type, even when its
    declaration cannot be resolved (a shim outside the project).
  - A persistence mechanism handle (a transaction, connection, session, query runner or entity manager type that is
    not a domain type) in a port signature counts as an adapter type.
- **R-TRANSPORT (new):** in domain, application or port code, an HTTP status code (100–599) assigned to a status
  property, or the construction or declaration of an HTTP or SQL error type.
