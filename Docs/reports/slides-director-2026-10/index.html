The problem

AI coding agents write code faster than anyone can review its architecture

  • Generated code compiles and passes tests, yet can quietly break layer rules, add cycles and couple modules.
  • A plain "review this against the architecture" prompt is not repeatable and cannot be audited.
Research question
Can an architecture spec be compiled into executable checks, backed by a frozen LLM judge, so that architectural conformance of agent-written code is measured deterministically, fast and with an audit trail?
