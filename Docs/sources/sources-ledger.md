# Sources ledger

**Date:** 2026-10-21. **Purpose:** one row per literature or evidence source the project has cited, so the thesis can cite each one from a single place and know how far it was read. Keys match `Docs/sources/sources.bib`. How the folder works: `Docs/sources/README.md`.

**How to read Status.** *read in full*: a repo note says the work (or its figures) was read in the full text. *summary only*: a repo note summarises it from the abstract, a snippet, documentation pages or a secondary source. *search summary only, not read in full*: known only from a search session's result summary. *unverified*: a bare mention, or an entry written from general knowledge (for example the paper bibs) with no reading recorded. Any figure from a source that is not *read in full* must be checked before the thesis quotes it (section "Figures the ledger cannot verify").

**Used in** lists the repo files whose text contains the source's identifier (arXiv id, DOI, bib key or a distinctive title or name), found by `git grep` over `Docs`, `ops`, `papers`, `scripts` and `demo`. Name-based matches (for example *Cockburn* or *Evans 2003*) can over-include. `[br] branch:path` marks a file that exists only on that branch. Lists longer than six paths are cut with "+N more".

**Scope.** Cited literature, benchmarks, datasets, tools and vendor or practitioner pages used as evidence. Not included: mined GitHub repositories and commits (they are data, listed in the corpus and DiagnosticRuns files), the project's own OSF registration, and named statistical procedures with no cited reference (Wilcoxon, McNemar, Fleiss' kappa, Krippendorff's alpha).
