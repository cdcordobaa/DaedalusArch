# Null results and limitations (v1.3)

This file consolidates the null and negative results and the stated limitations of the v1.3 instrument-validation work, as recorded in `Docs/v1.3/`, `Docs/DiagnosticRuns/v1.3-*` and `papers/` on 2026-10-16 (section 4: added by the daily thesis sync of 2026-10-17; section 5: added by the sync of 2026-10-19). Every entry cites the primary report that states it as `path:line`, with a second location where a later document adds to or corrects it. The "honest wording" column is a suggestion that the author may edit; it is written to avoid both overclaiming and softening, and it names the data scope (development set, external set of human-written projects, wild set) where that matters. At the time of writing, the sealed v1.3 hold-out has not been run and Study 2 has not been run, so no entry below is a validity estimate on held-out data or a Study 2 result. Figures labelled "development" come from data the instrument was built or tuned against.
