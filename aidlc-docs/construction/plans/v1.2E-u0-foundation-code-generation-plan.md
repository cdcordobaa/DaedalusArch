## Standard gates (referenced by steps)

- **Gate T (types)**: `npm run typecheck && npm run typecheck:u0-tests` (the second script exists from Step 5 on).
- **Gate U (unit and integration)**: `npm test` — total test count must equal the baseline (421) plus the tests U0 has added so far; zero failures. (Lint is not part of Gate U; see Gate L.)
- **Gate L (lint ratchet, from Step 11 on)**: `npm run lint 2>&1 | grep -cE "^\s+[0-9]+:[0-9]+\s+error"` ≤ the baseline recorded in Step 11, and no file touched in the step gains an error. Before Step 11 lint cannot run (D-U0-16).
- **Gate G (golden, unchanged)**: with Neo4j up, `GOLDEN_REQUIRED=1 npm run test:golden` exits 0 **and** its jest summary shows the expected number of executed, non-skipped tests (5 golden cases plus the infra tests: 2 from Step 7, 3 from Step 25 on; `0 skipped`) **and** `git diff --exit-code "$GOLDEN_BASE" -- tests/golden/__snapshots__` is empty, where `GOLDEN_BASE` is the commit made in Step 8. `GOLDEN_REQUIRED=1` is mandatory: without it a shell that lacks `NEO4J_PASSWORD` (the test does not load `.env`; only `src/cli/cli.ts` loads dotenv) skips the suite and jest still exits 0.
- **Gate G-CI**: the CI run on the pushed step commit shows the "Golden regression suite" step green. Required for Steps 9, 10, 11 (where CI first runs, and where the dependency tree changes) and at exit (Step 32); recommended after each contract group.
- **Gate B (test type-error budget)**: jest never type-checks (`isolatedModules: true`, ts-jest 29.4.6) and `tests/` is excluded from `npm run typecheck`. Run `npx tsc -p "$SCRATCH/tsconfig.tests-audit.json" | grep -c "error TS"` with the scratch (never committed) config whose exact content is fixed in Step 3. The count must not exceed the baseline recorded in Step 3 (85 expected), and no file touched in the step may appear in the error list with a new error. Test literals that would break at runtime are found by reading, not by the compiler.
- **Commit rule**: one commit per step (Step 8 snapshot commit alone). Conventional message naming the FR, e.g. `feat(u0): C10 enums — Package, FLOWS_TO, RE_EXPORTS, integrity (FR-09, FR-21, FR-22, FR-34)`. No commit touches `tests/golden/__snapshots__` after Step 8 (except a regeneration under Step 9's CI-mismatch rule, which moves `GOLDEN_BASE` while `src/` still equals `7cd15b4`).
