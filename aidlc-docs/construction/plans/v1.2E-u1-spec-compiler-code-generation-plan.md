## Standard gates (referenced by steps)

Shell preamble, at the start of **every Bash call** that runs a gate, a golden or container test, or a `cypher-shell` query in the worktree (each call is a fresh shell): `set -a; . "$HOME/.daedalus-u1.env"; set +a; unset CI` (D-U1-10; the file sets `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD`); `SCRATCH` = the session scratchpad. Never print, `cat` or `echo` the lane file or `$NEO4J_PASSWORD`.

- **Gate T (types)**: `npm run typecheck && npm run typecheck:u0-tests && npx tsc -p tsconfig.u1-tests.json` (the third from Step 4 on).
- **Gate U (unit and integration)**: `npm test` green, zero failures; total = the current baseline (592 before Step 11; re-recorded in Step 11) plus the tests U1 has added minus the tests U1 has deliberately removed (each removal named in the step's Done note).
- **Gate L (lint ratchet)**: `npm run lint 2>&1 | grep -cE "^\s+[0-9]+:[0-9]+\s+error"` ≤ the current baseline (L0 recorded in Step 3, expected 624; L1 re-recorded in Step 11), no file touched in the step gains an error, and every file U1 creates has 0 errors.
- **Gate B (test type-error budget)**: `npx tsc -p "$SCRATCH/tsconfig.tests-audit.json" | grep -c "error TS"` ≤ **85**, and no file touched in the step appears with a new error.
