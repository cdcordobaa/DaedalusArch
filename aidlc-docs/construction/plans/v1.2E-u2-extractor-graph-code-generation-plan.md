## Unit context

### Purpose
Make the extractor and the graph carry what the evaluation needs: Package nodes and `File -[:IMPORTS]-> Package` edges, alias-aware import resolution, merged IMPORTS edges with their FR-10 properties, per-name barrel resolution with RE_EXPORTS edges, FLOWS_TO edges, interface Method nodes with `Interface -[:CONTAINS]-> Method` (ADR-016 f), import-resolution counts and per-type graph counts, a repository with a default timeout, scrubbed errors and no password default. **U2 merges into `v1.2e` before U1 (ADR-015 item 12) and changes no golden snapshot (G0, BR-U2-45).** Every snapshot delta that the new graph enables lands later, in the U1 or U3 commit whose query reads it (`business-rules.md` §9, G1–G8).
