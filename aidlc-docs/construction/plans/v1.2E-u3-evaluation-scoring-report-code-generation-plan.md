### Purpose

## Standard gates (referenced by steps)

**Shell preamble** at the start of every Bash call that runs a gate, a golden or container test or a `cypher-shell` query: `set -a; . "$HOME/.daedalus-u3.env"; set +a; unset CI` (D-U3-3). `SCRATCH` = the session scratchpad. Never print, `cat` or `echo` the lane file or `$NEO4J_PASSWORD`.

- **Gate T (types)**: `npm run typecheck && npm run typecheck:u0-tests && npx tsc -p tsconfig.u1-tests.json && npx tsc -p tsconfig.u3-tests.json` (the last from Step 4 on; the U1 config is included because R6 edits U1 tests).
- **Gate U (unit and integration)**: `npm test` green, zero failures; total = Step 3 baseline `U_0` + tests added − tests deliberately removed (each removal named in the Done note).
- **Gate L (lint ratchet)**: `npm run lint 2>&1 | grep -cE "^\s+[0-9]+:[0-9]+\s+error"` ≤ `L_0` (Step 3); no touched file gains an error; every file U3 creates has 0 errors.
- **Gate B (test type-error budget)**: `npx tsc -p "$SCRATCH/tsconfig.tests-audit.json" | grep -c "error TS"` ≤ `B_0` (Step 3) with the U0 Step 3 scratch config verbatim, `<REPO>` = `<WT>`; no touched file gains an error; no `TS2688`.
