## 10. Hand-offs to other units

Universal orphan predicate, quoted once (FR-09 `:File` typing, Q16 A = U1 Q19 A, plan 5.2 barrel exclusion). U1 applies it to the `no-orphan-files` template, which also keeps its existing `f.layer IS NOT NULL` filter (`cypher-templates.ts:194`); U3 applies it to `universal-metrics.ts:25-28`:

```cypher
MATCH (f:File)
WHERE NOT EXISTS { MATCH (f)-[:IMPORTS|RE_EXPORTS]->(:File) }
  AND NOT EXISTS { MATCH (:File)-[:IMPORTS|RE_EXPORTS]->(f) }
  AND NOT f.isBarrel
RETURN count(f) AS cnt
```

**Orphan rule (ADR-016 g).** A file is an orphan when it has no `IMPORTS|RE_EXPORTS` relationship to or from a `:File` node, in either direction, and is not a barrel (`NOT f.isBarrel`). The universal orphan metric (U3, `universal-metrics.ts:25-28`) applies exactly this predicate and **no layer filter**, so it stays spec-independent (ADR-013). The `no-orphan-files` template (U1) applies the same predicate and keeps its existing `f.layer IS NOT NULL` filter (`cypher-templates.ts:194`), because it is a spec-bound check.
