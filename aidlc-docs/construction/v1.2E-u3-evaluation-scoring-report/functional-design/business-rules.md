### 2.1 `domain-purity` (exact)

```cypher
MATCH (src:File)-[i:IMPORTS|RE_EXPORTS]->(p:Package)
WHERE src.layer = $domainLayer
  AND ANY(fp IN $forbiddenImports WHERE p.name = fp OR (fp ENDS WITH '/*' AND p.name STARTS WITH left(fp, size(fp) - 1))) /*EXCLUDE:src*/
RETURN src.filePath AS source, p.name AS target, type(i) AS relType,
       CASE type(i) WHEN 'IMPORTS' THEN 'imports' ELSE 're-exports' END AS verb,
       i.line AS line, i.lines AS lines, coalesce(i.isTypeOnly, false) AS isTypeOnly
ORDER BY source, target, relType
```

The predicate before the marker is a top-level conjunction; the `OR` sits inside `ANY(…)` (BR-U1-44).

### 2.2 `domain-state-purity` (exact)

```cypher
MATCH (c:Class)-[e:FLOWS_TO|CONSTRUCTOR_INJECTS]->(t)
WHERE c.layer = $domainLayer AND t.layer = $infraLayer AND (t:Class OR t:Interface) /*EXCLUDE:c*/
RETURN c.filePath AS filePath, c.name AS class, t.filePath AS target, t.name AS targetName,
       type(e) AS relType, coalesce(e.field, e.parameterName) AS field, e.line AS line
ORDER BY filePath, class, target, relType, field
```

## 11. Threats-to-validity notes

1. **Correlated checks.** One domain→infrastructure injection fires FF-S01, FF-S04 and FF-P06. U5b counts the seeded instance once; AHS penalises it two or three times.
2. **Merged rows.** Merging identical ids keeps the first row's identity and line; evidence is the per-column maximum, so `inheritance-depth` reports the deepest excess depth but only one ancestor's line.
3. **SCC fallback.** No length bound; one violation per component, not per cycle; the baseline key changes when a seeded cycle merges SCCs and changes the smallest member (U5b matches SCC violations by member-set overlap). Cypher and SCC rows also use different `filePath` forms (`String(cycle)` vs smallest member); because a flip applies to the whole experiment, keys are never compared across strategies.
4. **Warning cap.** Individual warnings above 50 per (stage, code) are hidden; totals are kept in `REPORT_001`.
5. **Verdict thresholds across modes.** Calibrated on symbolic-only spike runs; full and neuronal-only verdicts use them unchanged (D-9). SO5 reports AHS values beside verdicts.
6. **Metric empty results.** `null` ratios and 0 max degrees on graphs without classes or file-to-file imports are definitions chosen before the first run.
7. **Data-flow check under the structural tag.** FF-P06 is `structural` (ADR-015 item 9) but checks a data-flow edge (SO2); U5b reports it as its own row inside `structural`.
8. **Injection rows without a line.** FF-P06 violations from `CONSTRUCTOR_INJECTS` are located by file, target and discriminator only.
9. **Evidence and id conventions.** Researcher choices, frozen (BR-U3-70).
10. **Hybrid pairs.** In full mode a violating symbolic half suppresses the neural half, so the `semantic` AVR rests on symbolic evidence for that function.
11. **Dropped-dimension rows.** A dropped dimension has no `perDimensionScores` row; readers must use `droppedDimensions` to see it (BR-U3-39).
12. **Judge dimensions without units.** A generated project that maps no file onto the evaluator layers drops `semantic`/`integrity` with `no-judge-units`, and `ahsCombined` is then computed over fewer dimensions; SO5 reports the drop count per cell beside the AHS values.
13. **Row weights in full mode.** Rows carry the `ahsCombined` weights; `ahsDeterministic` effective weights are recomputed offline (BR-U3-39), so a reader who takes row weights as symbolic weights in full mode is wrong by construction; the CSV header names the source.
