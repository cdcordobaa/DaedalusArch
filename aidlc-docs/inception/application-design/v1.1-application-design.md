# v1.1 Application Design — Architectonic Firewall (Consolidated)

## Design Summary

v1.1 extends the v1.0 architecture with 2 new components and 5 component extensions to support two parallel tracks: spec generation (Track A) and interactive dashboard (Track B), plus shared infrastructure (baseline, GeminiProvider).

### Component Inventory

| Component | Status | Track | Stories |
|-----------|--------|-------|---------|
| C3: Spec Parser | Extended (presets, exclude_paths, enabled, validation) | A | S-INIT-02, S-INIT-03, S-INIT-04, S-INIT-05, S-INIT-06 |
| C4: Fitness Compiler | Extended (WHERE NOT injection, enabled filter) | A | S-INIT-04, S-INIT-05 |
| C7: LLM Critic | Extended (GeminiProvider) | Shared | S-LLM-01, S-LLM-03 |
| C8: Scoring Engine | Extended (actionable violations, baseline status) | B | S-DASH-05 |
| C9: CLI | Extended (validate, report, baseline commands) | Both | S-DASH-04, S-INIT-06, S-INIT-07 |
| C12: Baseline Manager | **New** | Shared | S-INIT-07, S-INIT-08 |
| C13: Report Generator | **New** | B | S-DASH-01, S-DASH-02, S-DASH-03, S-DASH-04 |
| Skill: firewall-init | **New** (non-code) | A | S-INIT-01, S-INIT-08, S-INIT-09, S-INIT-10 |

### Key Design Decisions
1. **Presets extend C3** — YAML templates parsed by existing parser infrastructure
2. **Baseline is a new component C12** — separate lifecycle from evaluation scoring
3. **HTML report is a new component C13** — fundamentally different from text/JSON formatting
4. **Mining queries live in the skill** — Claude Code runs Cypher directly, no coded component
5. **GeminiProvider in C7** — extends existing LLMProvider interface with factory pattern
6. **Pipeline commands** — all new workflows (validate, report, baseline) use existing Command pattern

### Parallel Track Boundaries

**Track A touches**: C3, C4, C9 (validate/baseline commands), C12, Skill
**Track B touches**: C8, C9 (report command), C13
**Shared**: C7 (GeminiProvider), C10 (new types)
**Overlap**: C9 (both tracks add commands — no file conflict, separate command handlers)
