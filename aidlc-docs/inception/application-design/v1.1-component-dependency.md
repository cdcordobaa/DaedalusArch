## Dependency Descriptions

### C12: Baseline Manager
- **Depends on C8**: Reads violation list from EvaluationReport
- **Depends on C10**: Uses shared domain types (Violation, Severity, DomainResult)
- **No upstream dependencies**: C12 is a leaf component, nothing depends on it at execution time (invoked by CLI/pipeline)

### C13: Report Generator
- **Depends on C1**: Reads APGResult for graph node/edge data
- **Depends on C3**: Reads ParsedSpec for layer definitions, fitness function metadata
- **Depends on C8**: Reads EvaluationReport for scores, violations, dimension breakdown
- **Depends on C10**: Uses shared domain types
- **Optionally depends on C12**: Reads BaselineResult for baseline/new split (null if no baseline)

### Claude Code Skill
- **Depends on C9 (CLI)**: Calls `firewall evaluate`, `firewall validate`, `firewall baseline`, `firewall report`
- **Depends on Neo4j**: Runs mining Cypher queries directly
- **No code dependencies**: Skill is a prompt file, not a module

## Data Flow — New Pipelines

### Validate Flow
```
C3 (parse spec) → C3.validateSpec(spec, projectPath) → ValidationReport → C9 (output)
```

### Report Flow
```
C1 (extract) → C2 (ingest) → C3 (parse) → C4 (compile) → C5 (route) → C6/C7 (evaluate)
  → C8 (score + actionable format) → C12? (baseline compare) → C13 (HTML) → C9 (write file)
```

### Baseline Flow
```
C1 (extract) → C2 (ingest) → C3 (parse) → C4 (compile) → C5 (route) → C6/C7 (evaluate)
  → C8 (score) → C12 (create baseline) → C9 (write JSON)
```

### Skill Flow (Claude Code orchestrated, not coded pipeline)
```
Skill reads project structure
  → calls firewall evaluate --format json (full pipeline)
  → runs mining Cypher queries against Neo4j
  → classifies architecture from signals
  → selects preset + generates spec YAML
  → calls firewall validate
  → calls firewall baseline
  → calls firewall report
```

## Impact on v1.0 Dependencies

No v1.0 dependency arrows change. All new dependencies are additive:
- C3 gains preset loading (internal, no new external deps)
- C4 gains glob-to-regex (internal utility)
- C7 gains GeminiProvider (new external: `@google/generative-ai`)
- C8 gains actionable formatting (internal)
- C9 gains 3 new commands (internal, depends on C12 + C13)
