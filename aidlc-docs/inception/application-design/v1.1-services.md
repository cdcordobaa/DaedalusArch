# v1.1 Service Extensions — Architectonic Firewall

## S1: PipelineExecutor — Extensions

The existing PipelineExecutor (Command pattern) gains new command types for v1.1 workflows.

### New Pipeline Commands

```typescript
// Validate spec command (standalone, not part of evaluate pipeline)
class ValidateSpecCommand implements PipelineCommand {
  execute(context: PipelineContext): Promise<DomainResult<void>>
  // Calls C3.validateSpec() with parsed spec and project path
}

// Baseline create command (runs after evaluation)
class CreateBaselineCommand implements PipelineCommand {
  execute(context: PipelineContext): Promise<DomainResult<void>>
  // Reads violations from context.report, calls C12.createBaseline()
}

// Baseline compare command (runs before scoring when --baseline provided)
class CompareBaselineCommand implements PipelineCommand {
  execute(context: PipelineContext): Promise<DomainResult<void>>
  // Loads baseline, compares with current violations, enriches context
}

// Generate HTML report command (runs after scoring)
class GenerateReportCommand implements PipelineCommand {
  execute(context: PipelineContext): Promise<DomainResult<void>>
  // Calls C13.generate() with evaluation report + APG + spec + baseline
}
```

### New Pipeline Configurations

```typescript
// Validate pipeline: parse spec → validate
const validatePipeline = [ParseSpecCommand, ValidateSpecCommand]

// Report pipeline: full evaluation + HTML generation
const reportPipeline = [
  ExtractAPGCommand,
  ParseSpecCommand,
  IngestGraphCommand,
  CompileCommand,
  RouteEvaluateCommand,
  ScoreCommand,
  CompareBaselineCommand,     // optional, if --baseline
  GenerateReportCommand
]

// Baseline pipeline: full evaluation + baseline creation
const baselinePipeline = [
  ExtractAPGCommand,
  ParseSpecCommand,
  IngestGraphCommand,
  CompileCommand,
  RouteEvaluateCommand,
  ScoreCommand,
  CreateBaselineCommand
]
```

### Extended PipelineContext

```typescript
interface PipelineContext {
  // ... existing fields ...
  baselineResult?: BaselineResult     // NEW: populated by CompareBaselineCommand
  reportOutput?: ReportOutput         // NEW: populated by GenerateReportCommand
  validationReport?: ValidationReport // NEW: populated by ValidateSpecCommand
}
```

## S2: PipelineFactory — Extensions

```typescript
class PipelineFactory {
  // Existing
  createEvaluatePipeline(config: PipelineConfig): PipelineExecutor
  createBatchPipeline(config: BatchConfig): PipelineExecutor
  createDriftPipeline(config: DriftConfig): PipelineExecutor

  // NEW
  createValidatePipeline(config: ValidateConfig): PipelineExecutor
  createReportPipeline(config: ReportConfig): PipelineExecutor
  createBaselinePipeline(config: BaselineConfig): PipelineExecutor
}
```

---

## No New Services

v1.1 doesn't require new orchestration services beyond the PipelineExecutor extensions. The new components (C12, C13) are invoked as pipeline commands, fitting the existing Command pattern.

The Claude Code skill handles its own orchestration outside the codebase — it calls CLI commands sequentially.
