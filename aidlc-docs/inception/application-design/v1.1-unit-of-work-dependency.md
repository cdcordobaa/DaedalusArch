# v1.1 Unit of Work Dependencies

## Dependency Matrix

```
        U0    U1    U2    U3
U0       -     -     -     -
U1      DEP    -     -     -
U2      DEP    -     -     -
U3       -     -     -     -

DEP = depends on (must complete first)
```

## Dependency Details

| Unit | Depends On | Reason |
|------|-----------|--------|
| U0 | None | Foundation — shared types and parser/compiler extensions |
| U1 | U0 | Needs exclude_paths/enabled parsing (C3), shared types (C10), filterEnabled (C4) |
| U2 | U0 | Needs ActionableViolation type (C10), exclude_paths in compiled queries |
| U3 | None | Independent interface implementation — can build anytime after v1.0 base |

## Parallelization

- **U1 and U2 are fully independent** — different components, different directories, no shared state
- **U3 is independent** but deferred to post-merge for integration convenience
- **U0 is the critical path** — blocks both U1 and U2

## Cross-Unit Interfaces

### U0 → U1
- `SpecOverrides` type (C10)
- `ParsedSpec` extended with `exclude_paths` and `enabled` fields (C3)
- `CompiledFunctions.disabledFunctions` (C4)
- `ValidationReport` type (C10)

### U0 → U2
- `ActionableViolation` type (C10)
- Fitness functions with `exclude_paths` applied in Cypher (C4)

### U1 → U2 (at merge time)
- `BaselineResult` from C12 consumed by C13's baseline split view
- Both add commands to C9 — no file conflict (separate handler files)

### U3 → Everything
- `GeminiProvider` plugs into existing `LLMProvider` interface
- No changes to consuming code — factory pattern handles selection

## Risk Assessment

| Risk | Impact | Mitigation |
|------|--------|------------|
| U0 changes break 312 existing tests | High | Run full suite after U0, before creating worktrees |
| C9 merge conflict (both tracks add commands) | Low | Separate command handler files, Commander.js registration is additive |
| U2 depends on BaselineResult from U1 | Low | BaselineResult is optional in C13 — dashboard works without baseline |
| U3 Gemini API changes | Low | Interface is stable, implementation is isolated |
