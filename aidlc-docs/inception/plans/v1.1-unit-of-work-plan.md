**Unit granularity**: Given 2 new components, 5 extended components, and 1 skill, the decomposition options:

A) 5 units: U0-Shared (C10 types + C3 exclude/enabled + C4 WHERE NOT), U1-Presets (C3 preset loader + presets/), U2-Baseline (C12 + C9 baseline command), U3-Dashboard (C13 + C8 actionable + C9 report command), U4-Integration (C7 Gemini + C9 validate + Skill)
B) 4 units: U0-Shared (types + C3/C4 extensions), U1-TrackA (presets + baseline + validate + skill), U2-TrackB (dashboard + actionable violations + report command), U3-Gemini (GeminiProvider)
C) 3 units: U0-Shared (all shared extensions), U1-TrackA (everything Track A), U2-TrackB (everything Track B)
D) Other

[Answer]: B — 4 units maps cleanly to worktrees. U0 builds first in main (shared foundation), then U1 and U2 run in parallel worktrees, U3 integrates last.
