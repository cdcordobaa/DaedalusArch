# v1.2 Requirements — Minimal Scope Decision: Graph JSON Export (FR-16)

> **Stage**: v1.2 INCEPTION → Requirements Analysis · **Depth**: Minimal (reuse existing code, ship fast, test in prod)
> **Request**: A small, fast capability to write this project's architecture graph (APG) to a flat JSON file — reusing what already exists, not a from-scratch spec.

## Reuse analysis (why this is small)

The graph already gets built on every run; it's just never written out as a standalone artifact:

| Existing piece | Reused for |
|---|---|
| `extractAPG(projectPath, {excludePatterns})` → `APGResult {nodes, edges, parseCoverage, warnings}` | Produces the graph; **no Neo4j needed** |
| `FileSystemSnapshotStore` (`JSON.stringify(apg.nodes/edges, null, 2)`) | Proven JSON serialization of the APG |
| `baseline` / `report` CLI commands (`-o/--output`) | The "run → write a file" command template |

Net new work: ~30 lines wiring these together. No contract/schema changes, no Neo4j changes, fully additive & opt-in.
