```
+------------+  1. extraction   +-----------+  3. compiled rules  +------------+
|    code    | ---------------> |   graph   | ------------------> |  findings  |
+------------+                  +-----------+                     +------------+
                                      ^                                  |
+------------+  2. spec validity      |                                  |
|    spec    | ------------------------                 4. is it a real problem?
+------------+
```

| Link | Evidence today | Gap |
|---|---|---|
| 1. Code to graph | Every file parses; import resolution counts; seeded edges appear | No reference graph, so no edge precision or recall. File-to-layer *correctness* never checked. FLOWS_TO is near-empty. `import()` is not covered (all 6 SO4 misses; fix drafted in #69). |
