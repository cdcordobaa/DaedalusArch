Feature request:
Build the backend for a repair café, where volunteer fixers repair things that visitors bring in. The organiser sets up repair events (date, venue, opening hours) and the fixers who attend each one, with the categories they can repair (electrical, bikes, textiles, furniture). At the door, a visitor registers an item (category, brand and model, what is wrong with it, their name and mobile number) and gets a ticket number. A fixer takes the oldest waiting item of a category they can repair; a fixer works on one item at a time. When the fixer finishes, they record the outcome (fixed, advice given, not repairable) and the item's weight, and the visitor gets a text message saying the item is ready to collect. Text messages go through the café's account at TextLoop, whose HTTP API takes a mobile number and a message of at most 160 characters. Keep the data in memory and expose the operations over HTTP.
