Organise the code following Layered Architecture (presentation, business and persistence layers).
Organise the source code under src/ in exactly three folders: src/persistence, src/business and src/presentation.
The architecture has these rules:
- It is a violation when code in a lower layer imports code from a higher layer; from the bottom up the layers are persistence, business and presentation, and no dependency may point up.
- It is a violation when some files import each other in a circle.
- It is a violation when a layer imports a layer that is not directly below it, such as presentation code importing persistence code.
- It is a violation when business code imports code from the presentation or the persistence layer; the business layer must not depend on the other layers.
- It is a violation when business code imports a framework, an HTTP library or an I/O module.
- It is a violation when a repository class in the persistence layer does not implement an interface.
- It is a violation when a business class receives a persistence object through its constructor or holds one in a field.
