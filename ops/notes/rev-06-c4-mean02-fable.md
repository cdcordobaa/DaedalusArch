Verdict: Both notes do what REV-05 asked on paper: all ten items (a)–(j) have a home, the claims are scoped honestly, and the falsifiers are written before the data. Neither pilot can run as written: MEAN-02's vendor rule has no Gemini coding route behind it, C4's "most of it is built" rests on a SEM-only context builder that cannot take the symbolic findings that make up five of its six cases, and C4's call count for the non-author row is off by an order of magnitude on real repositories. The designs survive; the order of work and four construct statements need fixing before any count is approved.
B1. MEAN-02 has no second vendor that can write code. mean-02:102-104 alternates Claude-written twins with a Gemini agent and the reverse; writing a twin is a coding session (edit files, re-run C3, tsc, tests, :86-91). Gemini routes: the labeller agy home with writes, commands and MCP denied (src/llm-critic/agy-cli-provider.ts:17-20), the single-call GeminiProvider, and the generator adapter that a live grid refuses until a committed S4 result passes (scripts/lib/generators/agy-gen-cli.ts:5-7). So neither direction runs today; the 2-item pilot (:194) cannot start. Options: (i) single-vendor mechanics pilot, labelled; (ii) Gemini returns a unified diff via API and a zero-call script applies/validates it; (iii) wait for S4. Author decides.

B4.
