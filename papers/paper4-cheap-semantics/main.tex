\begin{abstract}
Architecture gates increasingly add an LLM judge for properties that structural rules cannot state, such as a
duplicated business rule or persistence leaking into the domain. Before paying for a judge, how much of that
semantics can deterministic code analysis compute? We built ten cheap proxies over an architectural property graph
and the TypeScript type checker and compared them with a frozen LLM judge and with symbolic layer rules on planted
anti-patterns. On seeds the proxies were designed against, they catch 11 of 11 against the judge's 9 of 11 and the
rules' 0 of 11, a circular result by construction. On six less circular hand-written analogues all three catch 6 of
6. On duplicated rules in generated code the proxies catch 1 to 2 of 9 and the judge 9 of 9. All figures are
development data. We describe an unbiased follow-up.
\end{abstract}

\section{Question}

An LLM judge can read intent, but it is slow, costs money per unit, varies between runs and shares blind spots with
the models that write the code. A deterministic proxy is the opposite: milliseconds, free, repeatable, but blind to
anything outside its tables. We ask: \emph{for which architectural anti-patterns does a cheap proxy suffice, and
where is the judge needed?} The answer decides how to layer a gate: rules decide, proxies propose candidates, the
judge interprets \citeneeded{garcez2023neurosymbolic}.
% src: Docs/v1.3/cheap-semantics-design.md ("Purpose": "A proxy proposes candidate sites. It does not give a verdict.")

\section{Instruments}

\textbf{Cheap proxies.} Ten deterministic detectors over the extracted graph and a type-checked project, with no LLM,
database or network: token clones with Type-2 normalisation \citeneeded{roy2007clones,kamiya2002ccfinder}, literals
shared across components \citeneeded{fowler1999refactoring}, name-versus-behaviour roles, LCOM4 cohesion, logic
density, direct ORM access outside repositories, framework types in core signatures, vocabulary leakage,
dependency communities (a diagnostic) and stored documentation text. Packages are identified through the type checker, never by import text alone.
% src: Docs/v1.3/cheap-semantics-design.md ("Placement and contract"; "The proxies"; "An import line alone is never enough"); Docs/DiagnosticRuns/cheap-semantics-2026-10-15.md §5 table columns
\textbf{Judge.} A frozen LLM judge with an unchanged rubric, three runs per unit and a majority vote, recorded and
replayed \citeneeded{zheng2023judging}. \textbf{Rules.} The v1.3 symbolic fitness functions of \tool{}.
% src: Docs/DiagnosticRuns/v1.3-judge-catch-2026-10-15.md §0
\textbf{Seeds.} Five frozen anti-pattern operators (repository bypass, fat controller, persistence in the domain,
duplicated rule, framework leak), each with a twin that should stay clean, plus hand-written violation variants of
five reference projects. % src: Docs/DiagnosticRuns/cheap-semantics-2026-10-15.md §1; Docs/v1.3/judge-catch-frozen.md

\textbf{(a) is circular by construction.} The proxies were written after the operators and the judge's first results
were read, and each operator has a designated proxy; 11 of 11 shows only that they implement what they were written to
detect. It still shows one complementarity: the proxies catch both framework leaks the judge missed (an unused
optional \texttt{request?: Request} parameter), because the type checker resolves the type whatever the body says.
Twin false flags were 2 of 42, both inherited from the base (0 of 42 paired). \devset{}

\textbf{(b) is less circular} and all three instruments agree: the persistence decorators and framework types are
type-checker facts, and the rules also see the package import. The proxies miss what their tables do not name: a
dependency-injection decorator in the domain, a serialisation library in a value object, and a fat application
service (density is measured only on controllers and adapters). \devset{}

\textbf{(c) is where the proxies fail.} Five of the eight generated duplications are bare guards, which the clone
filter drops; the other three are exact clones inside one component, which the cross-component rule ignores. Both
filters were added to silence false flags on clean code. The judge catches all nine, but its catch is confounded: every
run also calls the copied method a misplaced responsibility, and a foreign method alone fails five of five.

\textbf{Cost and precision.} The proxies take 71 to 99\,ms per reference project; the judge needed 261 calls for
the 11 round-1 seeds. On the five clean reference projects the proxies raise 14 defect flags, down from 101 before one
revision made on those same projects, so 14 is a tuned-on-development figure; several of the remaining flags are
arguably true duplications. \devset{}

\section{Reading}

Cheaply computable: anti-patterns that reduce to a resolved type, a decorator's package, or a call receiver (framework
types in signatures, ORM mapping in the domain, ORM handles outside repositories). Not cheaply computable:
judgements about responsibility and intent, and duplication whose copy is short, guard-shaped or local, where any
filter that keeps clean code quiet also hides the defect. A proxy's recall is bounded by its catalogue; a judge's
attribution is bounded by what else it notices. Neither has been measured on code nobody designed for.

\section{Design of an unbiased follow-up}

The follow-up removes the three sources of bias above. It is an informal design; whether to register it is an author
decision.
\begin{enumerate}[leftmargin=*]
  \item \textbf{Freeze before seeing positives.} Hash the proxies, thresholds and package tables before any seed is
        built or read; no definitional change after the freeze.
  \item \textbf{Seeds the proxy author never saw.} Positives from a label-free survey of real code and real fix
        commits, and from a second author's operators, written blind to the proxy tables; include anti-patterns
        outside every catalogue to measure the coverage limit.
  \item \textbf{Twins that change only the construct.} No added member, so a responsibility cue cannot stand in for
        the construct; for duplication, place the copy where the rule plausibly applies.
  \item \textbf{Human ground truth.} At least 30 items labelled by humans blind to instrument and rule, with
        agreement reported; a cross-vendor judge arm to measure same-vendor correlation.
  \item \textbf{Held-out precision.} Report false flags on a corpus of real projects not used for tuning.
  \item \textbf{A verification arm.} Give the judge each proxy candidate with its evidence and compare with blind
        judging, to test the layered gate directly.
\end{enumerate}
