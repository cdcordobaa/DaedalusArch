## Documented limits

- **L1-cycles-need-the-graph** (spec-only; FF-S02; full-only): A cycle is a property of the whole import graph. Without a project root the fast path sees only the changed files, so it cannot close a cycle (no-cyclic-deps is listed in notChecked).
- **L2-added-lines-only** (spec-only; FF-DT03; full-only): Without a project root a modified file is checked on its added lines only. A class-level fact (here a value object made mutable by an added setter or field) is a fact about the class declaration, and the added lines alone do not parse as one, so the member facts cannot be read.
