# PUZZLE-03 baseline results (arm `none`, exploratory, DEV split, not Study 2b)

Plan: `experiments/puzzle-03/plan.md` (committed before any call). Report: `Docs/DiagnosticRuns/puzzle-03-2026-10-23.md`.

| Path | What it is |
|---|---|
| `scores.json` | Per session and step: status, harness tsc count, tests (run from outside), oracle per sub-goal, size against the seed; the frozen instrument and DETECT-02 `check_consistency` on final trees; per-puzzle outcomes (`experiments/puzzle-03/score-baseline.ts`, zero calls) |
| `oracle-verdicts-to-read.md` | Every oracle FAIL on an agent tree, with a proposed label, plus the functional failures |
| `oracle-verdict-excerpts.md` | Code around each cited line (generated by the scorer) |
| `diffs/<session>/step-0N.diff` | The change of each step (step-01 is against the seed) |
| `sessions/<session>/` | `snap/step-00..03` (the seed and the tree after each step), `turns/step-0N/prompt.txt`, `session.json` |
| `run/` | `calls.jsonl` (the call ledger; the c01 step-03 line is the in-flight call lost to the container restart, added by hand), `turns.jsonl`, `schedule.json`, `redraws.jsonl`, `resumes.jsonl`, `smoke-result.json`, `input.json` |
| `isolation/` | Listing checks and fingerprint sweeps as the generator user, the READ probe result, the CLI wrapper |
| `private-id-map.json` | Session and task ids mapped to puzzle and run index (committed after generation) |

No agent message text is kept: envelopes are not committed, and the probe and smoke texts are replaced by a
placeholder.
